# newsmood — новости с эмоциональной окраской

**newsmood** — веб-приложение, которое берёт реальные новости из открытых источников и позволяет читать их в разных эмоциональных режимах: радостно, грустно, нейтрально или иронично. Факты остаются неизменными — меняется только подача.

Проект показывает работу с бэкендом на PHP, базами данных, интеграцию AI-инструментов и базовый фронтенд без фреймворков.

## Возможности

- Получение минимум 10 актуальных новостей из RSS-лент
- Автоматическое сохранение в SQLite
- Сетка новостей с переключателем настроения
- Динамическая подгрузка переписанного текста без перезагрузки страницы
- Детальная страница: оригинал и адаптированный текст, ссылка на источник
- Простейший контроль сохранения фактов (числа, даты, имена)
- Ручное обновление ленты через веб-интерфейс

## Технологии

- **PHP 8.4** — без фреймворков, без Composer и Docker, только стандартная библиотека
- **SQLite** — портативная база данных
- **RSS** — источники новостей (Lenta.ru, BBC, Meduza и др.), парсинг через SimpleXML
- **AI** — бесплатные LLM API (Groq / Z.ai / OpenRouter) для переписывания текста
- **HTML5, CSS Grid, Vanilla JS** — минималистичный интерфейс

## Источники новостей

RSS-ленты, прописанные в `NewsFetcher.php`:

- https://lenta.ru/rss
- https://www.bbc.com/russian/index.xml
- https://meduza.io/rss/all
- http://feeds.bbci.co.uk/news/rss.xml

При парсинге проверяется уникальность по URL, дубликаты не добавляются.

## Хранение данных

**Таблица `news`** — оригинальные новости  
`id`, `source_url` (уникальный), `source_name`, `title_original`, `content_original`, `pub_date`, `created_at`.

**Таблица `moods`** — доступные настроения  
`id`, `code` (happy, sad, neutral, ironic), `label`.

**Таблица `news_mood`** — переписанные варианты  
`id`, `news_id`, `mood_code`, `title_rewritten`, `content_rewritten`, `generated_at`.

Структура создаётся скриптом миграции при первом запуске.

## Как работает смена настроения

1. Пользователь выбирает настроение (радостное, грустное, ироничное, нейтральное).
2. JavaScript отправляет запрос на сервер.
3. Сервер проверяет, есть ли уже сгенерированный вариант для этой новости и этого настроения:
    - если есть — сразу возвращает,
    - если нет — отправляет оригинальный текст в AI API, получает переписанный, сохраняет в БД и кеширует.
4. Результат подставляется на страницу без перезагрузки.

Такой подход экономит токены и ускоряет повторные просмотры.

## AI и промпт-инжиниринг

Используется бесплатное API (Groq с Llama 3, GLM-5.2 или аналог).  
**Промпт**, гарантирующий сохранность фактов:

> Перепиши следующий текст в [НАСТРОЕНИЕ] тоне, строго сохранив все фактические данные: числа, даты, имена собственные, географические названия, цитаты, статистику. Не добавляй вымышленных событий. Не изменяй сути сообщения. Исходный текст: [ТЕКСТ]

Температура модели — около 0.7.

## Контроль фактов

Два уровня защиты от искажений:

1. **Жёсткие инструкции в промпте** (см. выше).
2. **Пост-проверка** в `FactChecker.php`:
    - из оригинала и переписанного текста извлекаются числа, даты, слова с заглавной буквы (простейшая эвристика имён и названий);
    - если какие-то из них пропали — новость помечается предупреждением.
3. В интерфейсе рядом с переписанным текстом может отображаться индикатор, если обнаружены расхождения.

Также рекомендуется выборочная ручная проверка нескольких новостей.

## Запуск проекта

1. **Клонировать репозиторий**  
   `git clone https://github.com/yourusername/newsmood.git`  
   `cd newsmood`

2. **Проверить PHP 8.4** и наличие модулей `pdo_sqlite`, `simplexml`, `curl`

3. **Настроить config.php**  
   Указать путь к файлу БД (можно оставить `database.sqlite`) и API-ключ выбранного AI-сервиса.

4. **Инициализировать БД**  
   Выполнить SQL из `migrations/001_create_tables.sql` (например, через `sqlite3 database.sqlite < migrations/001_create_tables.sql`)

5. **Загрузить новости**  
   `php update.php`

6. **Запустить сервер**  
   `php -S localhost:8000`  
   Открыть http://localhost:8000
